# Настройка робота как WiFi точки доступа

## Исправленные проблемы

✅ **WiFi подключение:** Улучшена стабильность точки доступа  
✅ **Система координат:** Робот теперь движется относительно начальной точки (0,0)  
✅ **Диагностика:** Добавлено подробное логирование всех действий  

## Параметры точки доступа

- **SSID (имя сети):** `RobotControl`
- **Пароль:** `12345678`
- **IP адрес робота:** `192.168.4.1`
- **Подсеть:** `192.168.4.0/24`
- **Канал:** 1
- **Максимум клиентов:** 4

## Как подключиться

1. **На компьютере/телефоне:**
   - Откройте настройки WiFi
   - Найдите сеть `RobotControl`
   - Подключитесь, используя пароль `12345678`

2. **IP адрес для доступа:**
   - Веб-интерфейс робота: `http://192.168.4.1`
   - Панель управления: `http://localhost:5002/robot-control`

## Использование веб-интерфейса

### Рекомендуемый способ: Панель управления
1. Подключитесь к WiFi сети `RobotControl`
2. Запустите сервис: `python service/app.py`
3. Откройте: `http://localhost:5002/robot-control`
4. **Новые функции:**
   - 🎯 Точное движение к координатам
   - 🔄 Сброс позиции в начальную точку
   - 🏠 Возврат домой по истории маршрута
   - 📊 Подробное логирование действий

## Система координат

**Теперь робот работает с абсолютными координатами относительно начальной точки (0,0):**

- **Стартовая позиция:** X=0, Y=0
- **Команда `GO_LOCAL 50 30`:** Движение к точке X=50см, Y=30см от начала
- **Координаты в сантиметрах** от начальной точки
- **Автоматический поворот** к целевой точке

## Команды робота

- `GO_LOCAL X Y` - Движение к точке (X,Y в см от начала)
- `RESET_POS` - Сброс позиции в (0,0)
- `RETURN_HOME` - Возврат домой по истории
- `UP` - Поднять подъёмник
- `DOWN` - Опустить подъёмник  
- `DELAY N` - Задержка N миллисекунд

## Пример использования

1. Загрузите код на ESP32
2. Откройте Serial Monitor (115200 baud)
3. Дождитесь сообщения:
   ```
   ✅ WiFi Access Point успешно создан!
   📡 SSID: RobotControl
   🌐 IP адрес: 192.168.4.1
   ```
4. Подключитесь к сети `RobotControl`
5. Откройте панель управления
6. **Сбросьте позицию:** нажмите "Reset Position"
7. **Отправляйте координаты:** введите X,Y и нажмите "Go to Point"

## Диагностика подключения

**Если не удается подключиться к WiFi:**
1. Проверьте Serial Monitor - должна появиться точка доступа
2. Убедитесь что ESP32 получает достаточное питание
3. Перезагрузите ESP32
4. Попробуйте подключиться с другого устройства

**Если робот движется неправильно:**
1. Нажмите "Reset Position" для сброса координат
2. Проверьте логирование в Serial Monitor
3. Убедитесь что колеса двигаются в правильном направлении

**Логирование в Serial Monitor:**
```
📥 Получена команда: GO_LOCAL 50 30
🎯 Движение к точке: X=50.0, Y=30.0
📍 Текущая позиция: X=0.0, Y=0.0, Угол=0.0
🔄 Нужно повернуть на 31.0°, расстояние: 58.3см
⬅️ Поворот влево
⬆️ Движение вперед на 58.3см
✅ Движение завершено
```
