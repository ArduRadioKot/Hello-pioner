# Hello Pioneer — Система инвентаризации складов с дроном

Веб-приложение для автоматической инвентаризации складов с использованием дрона Geoscan Pioneer: распознавание топологии плана, построение графа, планирование маршрута облёта и распознавание QR-кодов в узлах.

---

## Возможности

- **Загрузка и анализ карты** — распознавание стен и стеллажей на плане (OpenCV)
- **Построение графа** — узлы в клетках, рёбра между соседними, учёт стеллажей
- **Маршрут облёта** — алгоритм Дейкстры + эвристика ближайшего соседа для посещения всех узлов
- **Симуляция** — полёт иконки дрона по маршруту на карте
- **Управление дроном** — взлёт, полёт по точкам, посадка через Pioneer SDK
- **QR-коды** — распознавание при облёте (pyzbar, OpenCV), сохранение и показ по клику на узел
- **Видеопоток** — трансляция с камеры дрона с отображением QR-кодов (опционально)
- **Направление оси Y** — выбор двойным кликом по соседней клетке для калибровки системы координат

## Используемые технологии

### Backend (Python)

| Пакет | Версия | Назначение |
|-------|--------|------------|
| **Flask** | ≥3.0 | Веб-фреймворк, REST API |
| **opencv-python-headless** | ≥4.8 | Распознавание топологии, обработка кадров, детекция QR |
| **numpy** | ≥1.24 | Вычисления для компьютерного зрения |
| **pioneer_sdk** | ≥0.0.1 | Управление дроном Geoscan Pioneer, камера, MAVLink |
| **pyzbar** | ≥0.1.9 | Распознавание QR-кодов (основной детектор) |

### Frontend

- **HTML5** — разметка
- **CSS3** — стили, модальные окна, адаптивная сетка
- **JavaScript (ES5)** — логика, canvas, fetch API, без фреймворков

### Внешние системы

- **Geoscan Pioneer** — дрон с камерой и MAVLink-связью
- **Jinja2** — шаблонизатор Flask

## Установка и запуск

### 1. Окружение

```bash
cd helloPioner
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
# .venv\Scripts\activate    # Windows
```

### 2. Зависимости

```bash
pip install -r service/requirements.txt
```

Для **pyzbar** может потребоваться системная библиотека:
- Ubuntu/Debian: `sudo apt install libzbar0`
- macOS: `brew install zbar`

### 3. Запуск сервера

```bash
cd service
python app.py
```

Сервер будет доступен по адресу: **http://127.0.0.1:5002**

### 4. Дрон

Подключите дрон Geoscan Pioneer к той же сети, что и компьютер. Pioneer SDK использует Wi‑Fi и MAVLink для связи.

## API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/` | Главная (роботы) |
| GET | `/new-task` | Страница создания задачи |
| POST | `/api/analyze-topology` | Распознавание топологии (image) |
| GET/POST | `/api/graph` | Получить/сохранить граф |
| POST | `/api/drone/start` | Запуск миссии |
| POST | `/api/drone/land` | Посадка |
| GET | `/api/drone/status` | Статус миссии |
| GET | `/api/drone/frame` | Кадр камеры (JPEG) |
| GET | `/api/drone/frame-with-qr` | Кадр + распознавание QR |
| GET | `/api/nodes/qr` | QR-данные по узлам |

## Алгоритмы

- **Граф** — сетка клеток, стеллажи как препятствия, соседство 4-связности
- **Маршрут** — Дейкстра для кратчайшего пути между узлами, nearest-neighbor для обхода всех узлов, возврат в старт
- **Координаты** — преобразование клеток (i, j) в метры (x, y) с учётом `scaleX`, `scaleY` и направления оси Y

---

## Файлы данных

- **graph.json** — узлы, рёбра, мета (nx, ny, scaleX, scaleY, walls)
- **nodes_qr.json** — `{ "node_id": "содержимое QR" }`, только непустые
- **robots.json** — список роботов для главной страницы
